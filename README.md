# Proiect_SMA

SMART PARKING
Descriere:
Aplicatie Android pentru monitorizarea locurilor de parcare si contorizarea masinilor care intra in parcare.

Functionalitati:
-Autentificare si inregistrare utilizatori.
-CRUD pentru locurile de parcare.
-Monitorizarea locurilor libere si ocupate.
-Contorizarea masinilor cu ajutorul senzorilor.
-Afisarea statisticilor si a istoricului.

Senzori
-detectarea ocuparii locurilor.
-detectarea si contorizarea masinilor care intra/ies.

Tehnologii
Android Studio, Kotlin, XML

Obiectiv
Dezvoltarea unei aplicatii mobile pentru gestionarea eficienta a locurilor de parcare.
